# User Dashboard UAT

## Submitted Requests

1. Log in as a regular user with at least one saved textile submission.
2. Open `/dashboard`.
3. Confirm the request count cards remain visible and open the dedicated My Requests page when clicked.
4. Click the My Requests dashboard shortcut and confirm `/my-requests` opens.
5. Confirm My Requests lists only the logged-in user's submissions after refresh/relogin.
5. Confirm each request row shows item/submission name, pathway, partner routing, status, submitted date, DSS confidence, and DSS score when available.
6. Use the All, Pending, Accepted, Completed, and Rejected filters and confirm matching rows are shown.
7. Search by item name, pathway, partner, or status and confirm matching rows are shown.
8. Click View Details and confirm the modal shows submission details, uploaded images, DSS recommendation details, partner brief status, and a messages shortcut.
9. Click Open DSS or Open Full Details and confirm the existing DSS detail page opens for that submission.
10. Log in as another user and confirm the first user's submissions are not visible.
